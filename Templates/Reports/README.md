# Report Templates

> Shared starting points for new reports.

## Status

This folder is a stub. No content has been written yet.

## Guidance

When adding a template, strip anything specific to the report it came from.
A template that still contains a real dataset name or a customer's slicers
gets copied, and the residue becomes someone else's bug.
