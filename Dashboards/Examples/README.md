# Dashboard Examples

> Reference dashboard implementations.

## Purpose

These examples exist to show layout and storytelling patterns end to end. They
are references, not templates — copy the structure, not the content.

## What a good dashboard does

- **Answers one question per page.** If a page needs a paragraph to explain,
  it is doing too much.
- **Leads with the headline metric,** then the breakdown that explains it.
- **Fixes the filter context visibly** so the reader knows what they are
  looking at.
- **Uses consistent visual positions** for the same measure across pages.
