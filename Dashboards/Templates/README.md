# Dashboard Templates

> Starting points for new dashboards.

## What belongs in a template

- Page structure and visual positions for a common scenario.
- Slicers and filters a reader is expected to use.
- Placeholder measures with naming that signals where real measures go.

## What does not

- Real data or hard-coded values. A template that ships with data gets copied
  with the data, which is how stale numbers reach production.
- Sensitivity labels or workspace settings; those are set per environment.
