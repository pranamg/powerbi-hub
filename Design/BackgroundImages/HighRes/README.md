# High Resolution

> High-resolution background images.

## Using backgrounds

- **Right-click the report page → Format → Canvas settings → Type → Image** to
  set a page background.
- Provide a **light and dark variant** if the report supports both themes. A
  light image behind dark-mode text makes content unreadable.
- Keep text off the busiest part of the image, or place content on a panel
  with a solid fill rather than directly on artwork.
- **Compress images.** Large backgrounds inflate the report file and slow
  every page render.
