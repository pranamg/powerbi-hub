# Low Resolution

> Low-resolution background images.

## Purpose

Lower-resolution backgrounds are useful for email reports, mobile layouts,
and slide exports, where the rendering target is much smaller than a desktop
browser. They are also a reasonable compromise for report previews.

## Guidance

- Match the **aspect ratio** of the target surface, or the image will crop
  unpredictably.
- Keep the file size small; these are often the first thing to bloat a report.
