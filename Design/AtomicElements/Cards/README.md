# Cards

> KPI card designs.

## Design guidance

- **One number, one meaning.** A card that mixes values forces the reader to
  work out which is the answer.
- Always show the **measure name and unit**, and a comparison period where one
  adds context. A bare figure is rarely interpretable.
- Use `DIVIDE` for ratios so a zero denominator returns blank rather than an
  error or a misleading zero.
- Apply **conditional formatting** for thresholds and trends, but keep the
  threshold logic in a measure or a field parameter so it is consistent across
  pages.
- Match font size and number format to the card's visual weight; a hero KPI
  should dominate, a secondary KPI should not compete with it.
