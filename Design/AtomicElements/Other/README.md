# Other

> Atomic elements without a dedicated folder.

## Examples of what belongs here

- KPI and status indicators such as gauges and progress rings. See
  [Progress_Ring.dax](../../../Visuals/CustomVisuals/SVG/Progress_Ring.dax).
- Text and shape elements used as headers or annotations.
- Icons and badge visuals, e.g.
  [RAG_Icons.dax](../../../Visuals/CustomVisuals/SVG/RAG_Icons.dax).

## When to add a folder

If a family of elements grows, give it its own folder. A folder with two
related items is fine; a folder with ten unrelated ones is not.
