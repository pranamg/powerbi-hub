# Design Best Practices

> Practices that keep reports usable as they grow.

## Layout

- **Align visuals to a grid.** Free-placed visuals are the main reason a
  report looks unfinished.
- Keep consistent **sizes for recurring elements** — a KPI card should occupy
  the same position on every page that has one.
- Leave **whitespace**. Cramming content is not the same as using space well.
- Check the report on a **laptop screen** as well as a large monitor; that is
  how most people will read it.

## Colour

- Use a theme rather than formatting visuals one at a time. See
  [Themes](../Themes/).
- Reserve **colour for meaning** — status, variance, highlight. Decorative
  colour competes with the signal.
- Check contrast against WCAG guidance; roughly 4.5:1 for body text.
- Never rely on colour alone to convey meaning; pair it with a label, icon, or
  position, so it survives both colour blindness and greyscale printing.

## Consistency

- Same measure, same visual, same position, same number format. This is the
  single biggest driver of perceived quality.
- Write a **one-line purpose** for each page. If it needs a paragraph, split
  it.

## Accessibility

- Descriptive titles and alt text on visuals.
- Logical reading order, and navigation order that matches it.
- Do not rely on hover-only interaction for essential information.
