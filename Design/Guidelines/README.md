# Design Guidelines

> House standards for report and dashboard design.

## Principles

1. **Answer a question.** Every page exists to communicate something specific.
2. **Consistency over novelty.** Reusing a pattern the reader has already
   learned is worth more than a better-looking first impression.
3. **Progressive disclosure.** Lead with the summary, keep detail one
   interaction away.
4. **Visible context.** Always show the active filters and the time period.

## Applying a theme

## Checklist for a new report

- [ ] Theme applied, no manual visual overrides
- [ ] Title states the page's question
- [ ] Slicers present and limited to the useful few
- [ ] Number formats consistent with other reports
- [ ] Reviewed on a laptop screen
- [ ] Alt text added to visuals
- [ ] Navigation order is logical from every page
