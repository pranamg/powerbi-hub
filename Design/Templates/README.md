# Design Templates

> Design template documents for reports and dashboards.

## What these cover

Layout, theming, and visual conventions — the *look* of a report — as distinct
from [Templates/](../../Templates/), which cover reusable report and dashboard
structures.

## Using a template

1. Decide the page structure and visual positions for each page.
2. Apply the house theme, then set out the visuals on the grid.
3. Replace placeholder measures with real ones, keeping the naming pattern.
4. Delete anything the report does not need rather than leaving it hidden.
