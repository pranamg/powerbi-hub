# Comments

> Using report and dataset comments for review feedback.

## Where comments live

- **Report comments** — anchored to a report page or a specific visual.
- **Dataset comments** — anchored to a table, column, or measure in Desktop.
- **Workspace comments** — general notes attached to the workspace.

Comments are visible to anyone with at least Viewer access, so avoid putting
sensitive information in them. They are also not private during review; use
them for discussion, not for approval sign-off that needs an audit trail.

## Review practice

1. Comment on the specific visual or field rather than the report as a whole.
2. State the problem and the expected outcome together, so the author does not
   have to ask which behaviour you meant.
3. Resolve threads once addressed. Unresolved comments tend to be ignored.
4. Move the decision into [ChangeManagement.md](../../Governance/ChangeManagement.md)
   if it affects more than one report.
