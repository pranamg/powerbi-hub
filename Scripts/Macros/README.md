## Scope

Power BI Desktop's macro support is limited compared with Excel, and
automation that depends on it is fragile across versions. Where a task can be
done in **Tabular Editor**, PowerShell, or the REST API, prefer that: it is
version-independent and can be run in CI.

Use macros only for genuinely Desktop-specific interactions.
