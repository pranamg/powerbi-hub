# Dataset Examples

> Reference dataset implementations.

## What a dataset is in this context

The semantic model and its data source, as it would be published. These
examples show a complete, publishable arrangement rather than isolated DAX.

## Reviewing an example

Check the example against the standards it is meant to demonstrate:

- Is the date table marked correctly?
- Are relationships and filter directions as expected?
- Do measures use variables rather than repeated `CALCULATE` calls?
- Is description text populated on tables, columns, and measures?
