# Other

> Sources without a dedicated folder.

## When to add a folder instead

If a source needs real guidance — a connector with non-obvious settings, or a
pattern people get wrong — give it its own folder rather than adding it here.
A folder named after the source is far easier to find.

## What belongs here

- One-off or rarely used connectors that need only a short note.
- A pointer to where the source is owned or documented elsewhere.
