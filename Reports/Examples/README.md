## What a useful example provides

- A **complete page** that answers a real question, not a visual gallery.
- A clear **filter context** with visible slicers.
- Consistent use of a theme and number formats, so it doubles as a
  demonstration of the house style.
- A short note on what the report shows and which measures it depends on.
