# Layouts

> Report and dashboard layout definitions.

## Status

This folder is a stub. No content has been written yet.

## What belongs here

- Page **canvas layouts** for phone, page, and 4:3 formats.
- Reusable **grid and background structures** that can be dropped onto a page.
- Dashboard arrangements that coordinate several reports.

## Guidance

A layout is only useful if it is **editable**. Prefer a PBIR layout definition
or a documented grid over a screenshot, and record which page size it assumes.
Remember to set **page view** and **page order**, not just visual positions.
