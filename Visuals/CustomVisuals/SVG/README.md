# SVG Custom Graphics with DAX

> **Purpose:** Create custom visual elements using SVG generated by DAX measures

---

## Overview

SVG (Scalable Vector Graphics) can be generated directly from DAX measures, enabling custom icons, shapes, and simple charts without any external dependencies.

## How It Works

1. Create a DAX measure that returns SVG markup
2. Use Data URI format: `data:image/svg+xml;utf8,<svg>...</svg>`
3. Set measure data category to "Image URL"
4. Add to table visual or image component

## Setting Data Category

```
1. Select the measure in model view
2. In Properties pane, find "Data category"
3. Set to "Image URL"
```

## Limitations

- Must use data:image/svg+xml format
- Limited complexity (simple shapes work best)
- URL encoding needed for special characters
- Some SVG features not supported in all browsers

---

## Tips

### URL Encoding
Replace these characters in SVG:
- `#` → `%23`
- `<` → `%3C`
- `>` → `%3E`
- `"` → `'` (use single quotes)

### Testing
- Test SVG in browser first
- Use online SVG validator
- Keep SVG simple for best compatibility
