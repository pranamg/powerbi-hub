# Power Query Custom Functions

Reusable M functions for common data transformation tasks.

## Available Functions

| Function | Purpose |
|----------|---------|
| `fnDateTableGenerator.m` | Generate date dimension table |
| `fnErrorHandler.m` | Wrap functions with error handling |
| `fnDynamicDataSource.m` | Switch data sources by environment |
| `fnParameterTable.m` | Create What-If parameter tables |
| `fnCleanText.m` | Clean and transform text |

## How to Use

1. In Power Query Editor, create a new Blank Query
2. Open Advanced Editor
3. Paste the function code
4. Rename the query to the function name
5. Invoke the function in other queries
